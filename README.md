# ヒット&ブロー 2人対戦

1台の端末を2人で使って遊ぶ、数字（または色）当てゲーム「ヒット&ブロー」のブラウザアプリです。
ビルド不要の HTML / CSS / JavaScript だけで動きます。

## あそびかた

1. コンピューターが数字（または色）の並び（**お題**）をランダムに1つ決めます。
2. 2人で交互に、同じお題を予想して「コール」します。
3. コールするたびにヒントが出ます。
   - **ヒット**（赤いピン）… 数字（色）も位置も合っている
   - **ブロー**（白いピン）… 数字（色）は合っているが位置がちがう
4. 先にお題をすべてヒットさせた人の勝ち！

### 駆け引き

コールもヒントも **2人とも丸見え** です。自分のコールで答えがしぼれると、次の番の相手に先に当てられてしまいます。
攻めすぎず、相手に手がかりを渡しすぎないコールを考えるのがポイントです。
答えの候補がいくつ残っているかはプレイ中は表示されません。対戦が終わると、各コールのあとに候補が何通り残っていたかを振り返れます。

### ルール設定

| 設定 | 内容 |
| --- | --- |
| ピンの数 | 3〜5（標準 4） |
| 種類の数 | 4〜8種類（標準 6種類） |
| コールできる回数 | 各5〜10回 / 無制限。2人とも使い切ったら引き分け |
| 持ち時間（1人あたり） | なし / 1・2・3（標準）・5・10分。自分の番の間だけ減り、0になったら負け |
| 1回のコールの制限時間 | なし（標準） / 15・30・60秒。過ぎるとパス（コール1回分を使う） |
| ピンの見た目 | 数字（1〜8、標準）または色 |
| 同じものを何度も使える | オンにすると難易度アップ |

時計を使う対戦では「一時停止」で時計を止められます（止めている間は盤面も隠れます）。
「もう一度」で先攻・後攻を交代して再戦でき、通算成績も表示されます。
色で遊ぶときは色ごとに記号（●▲■◆★♥✚☾）が付くので、色が見分けにくくても遊べます。

## 起動方法

ES Modules を使っているため、ファイルを直接開くのではなくローカルサーバーで配信してください。

```sh
python3 -m http.server 8080
# または
npm start
```

ブラウザで http://localhost:8080 を開きます。GitHub Pages などの静的ホスティングにそのまま置くこともできます。

## テスト

```sh
npm test
```

判定（ヒット/ブローの計算）、候補数の計算、勝敗・引き分けの判定ロジック（`js/logic.js`）を Node.js 標準のテストランナーで確認します。

## ファイル構成

```
index.html        画面
css/style.css     見た目
js/logic.js       ゲームロジック（DOM に依存しない）
js/app.js         画面の制御
tests/            ロジックのテスト
```
