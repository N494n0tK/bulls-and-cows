# ヒット&ブロー 2人対戦

1台の端末を2人で使って遊ぶ、色当てゲーム「ヒット&ブロー」のブラウザアプリです。
ビルド不要の HTML / CSS / JavaScript だけで動きます。

## あそびかた

1. おたがいに、相手に見えないように **色の並び（秘密のコード）** を決めます（端末を順番にわたします）。
2. 先攻・後攻で交互に、相手のコードを予想して「コール」します。
3. 予想するたびにヒントが出ます。
   - **ヒット**（赤いピン）… 色も位置も合っている
   - **ブロー**（白いピン）… 色は合っているが位置がちがう
4. 先に相手のコードをすべてヒットさせた人の勝ち！

相手の予想とヒントも同じ画面に出るので、相手がどこまで迫っているかを見ながら作戦を立てられます。

### ルール設定

| 設定 | 内容 |
| --- | --- |
| ピンの数 | 3〜5（標準 4） |
| 色の数 | 4〜8色（標準 6色） |
| 回答できる回数 | 各6〜12回 / 無制限。使い切ったら引き分け |
| 同じ色を何度も使える | オンにすると難易度アップ |
| 最後のチャンス | 先攻が当てても、後攻に同じ回数のチャンス。後攻も当てれば引き分け |

「もう一度」で先攻・後攻を交代して再戦でき、通算成績も表示されます。
色ごとに記号（●▲■◆★♥✚☾）が付いているので、色が見分けにくくても遊べます。

## 起動方法

ES Modules を使っているため、ファイルを直接開くのではなくローカルサーバーで配信してください。

```sh
python3 -m http.server 8080
# または
npm start
```

ブラウザで http://localhost:8080 を開きます。GitHub Pages などの静的ホスティングにそのまま置くこともできます。

## テスト

```sh
npm test
```

判定（ヒット/ブローの計算）や勝敗・引き分けの判定ロジック（`js/logic.js`）を Node.js 標準のテストランナーで確認します。

## ファイル構成

```
index.html        画面
css/style.css     見た目
js/logic.js       ゲームロジック（DOM に依存しない）
js/app.js         画面の制御
tests/            ロジックのテスト
```
